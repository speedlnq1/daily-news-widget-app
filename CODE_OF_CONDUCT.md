# Code of Conduct

We want this project to be a friendly, respectful place for everyone, whatever their background or experience.

## Expected behaviour
- Be kind and patient, especially with newcomers.
- Give and accept constructive feedback; criticise ideas, not people.
- Assume good intent and stay on topic.

## Unacceptable behaviour
- Harassment, insults, discrimination or personal attacks.
- Publishing other people's private information.
- Spam, or using the issue tracker to push unrelated political or commercial messages.

Because this app shows news, discussions about *the app* (what it ranks, which outlets it trusts) are welcome, but arguments about the news stories themselves are off topic here.

## Enforcement
Maintainers may edit or remove comments, close threads, and block people who break these rules. To report a problem, use GitHub's "Report content" feature or open a private security advisory titled "Conduct" on this repository.

This code of conduct is adapted from the Contributor Covenant, version 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
